# 迹库 / Tracebook（迹库）

**用户自己的资料与记忆系统。** 把录音、本地工具输入和已有文字资料归集到自己的文件夹，保留来源、版本和人工修改，再逐步整理成可确认、可更正的个人记忆。

An early-stage personal memory system with native Apple clients and user-owned files.

[开发说明](docs/development.md) · [架构与能力](docs/architecture.md) · [持续迭代清单](ROADMAP.md) · [参与开发](CONTRIBUTING.md) · [安全说明](SECURITY.md)

产品体验以 [Auday（录音与记忆应用）的流程研究](docs/auday-experience.md)为主要对照，保留本项目的多来源资料、用户文件夹和个性化采集入口。后续官网开发可从[云电脑协作交接](docs/website-brief.md)开始；官网目前尚未实现。

## 当前能做什么

| 能力 | 当前状态 |
| --- | --- |
| 录音与回放 | 手机、手表采集，支持暂停、保存、恢复与回放；录音中可保存重点时间位置，三端可按标记回听，暂停和中断后保留位置，多种快捷入口共用采集链路 |
| 本地工具输入 | Codex（编程助手）与 Claude Code（编程助手）目录发现、预览确认、增量归档和统计；支持已适配的压缩历史、暂停与恢复。扫描详情可按行号及字节位置核对跳过记录，旧位置缺失会明确提示 |
| 文字资料导入 | 支持 `.md`、`.markdown`、`.txt`、`.text`、PDF（便携文档）已有文字及 DOCX（办公文档）的正文、表格与附注；先预览覆盖，再确认，保留页码或提取段落、来源版本与人工修改。可指定本人原文、转录或模型生成等资料性质，更正性质另存版本；Mac（苹果电脑）可明确启用扫描页本机 OCR（文字识别），每份最多尝试 10 个无文字层页面；独立图片文件尚未支持 |
| 聊天导入 | 读取用户导出的 JSON（结构化文本）或 ZIP（压缩包）；区分用户与助手，保留原日期与来源 |
| 文件持有 | 用户自选资料夹；保留历史和人工修改，文字可导出。导入时可明确保留 PDF（便携文档）与 DOCX（办公文档）原件副本，已有资料可补存原件，电脑可校验后另存原文件 |
| 启动资料库 | 电脑可核对并记住已有资料库，正常重开继续使用；文字目录位于库外时单独选择授权。资料库或文字归档位置失联时不新建替代目录；归档目录被替换时须核对完整文件后重新关联。恢复原位置后可重试，手机重试同时刷新资料库状态。切换先暂停接收和自动处理，保留原库与按库隔离的编辑草稿。资料夹搬动后可明确选择并核对完整文字位置，重新关联现有文件，保留人工修改与历史 |
| 记忆文件核对 | 人工文件与生成内容可保留、采用或手动编辑合并；先备份，草稿按资料库隔离，过期预览拒绝覆盖，中断可继续同次操作。合并只改变导出文件，原文与记忆事实不变 |
| 转写核对 | 人工文字与机器转写冲突时，两端可比较并明确保留、采用或手动合并；替换前备份，草稿按资料库隔离，过期预览拒绝覆盖，保存结果不自动确认记忆 |
| 归档目录 | 更换位置会核对并复制受支持的文字、历史、备选版本和已保留的文档原件，保护人工改动；不同内容不覆盖，中断后复用已完成副本。原目录与原音保留，重开按已保存的复制回执核对位置 |
| 备份与还原 | 电脑设置可备份已接收原音、归档文字、已保留的文档原件、记忆与历史，校验后恢复到独立副本。人工改动的原件副本也会保留，并在预览中标明；未留存的附件、应用凭证和未确认导入不包含在内；原资料夹只读但完整可读时仍可备份，备份成功与重新打开失败分别显示 |
| 资料对话 | 先本地检索，再明确选择片段、预览并请求独立配置的回答模型；结论保留原文引用，失败保留检索，重启后须明确重试。真实回答质量尚未验收 |
| 每日分析 | 已有可配置文字模型适配器、引用和失败保护；真实模型质量尚未验收 |
| 记忆 | 四类文字来源可手动提出候选，或明确选择单份资料生成模型建议；保留原文版本、引用、模型与历史，支持审阅确认、修订、停用和恢复。支持明确发送所选新旧记忆及其保存依据，请模型提出关系建议；保留双边引用与核对历史，处理方式仍由用户决定。已支持最多 20 组配对集中预览、逐组核对、暂停与失败恢复；重启后明确继续，已保存结果复用。真实模型质量与后台批量计划仍待完成 |
| 传输与同步 | 持久队列、校验、去重、接收回执与资料夹交换已有；真实云盘异地及后台链路仍待验收 |
| 外部只读接入 | 独立凭证、明确资料范围、到期与撤销；附客户端和接口描述 |

**这是早期源码版本。语音转写适配器与任务队列已实现，真实识别质量仍待验收；复杂文档解析、统一模型记忆整理和真实云端同步尚未全部完成。** 不提供已公证安装包，也不承诺克隆后即可获得完整自动记忆服务。具体缺口和验收标准见 [ROADMAP（迭代清单）](ROADMAP.md)。

## 从源码开始

需要 Xcode（苹果开发工具）26 或以上及手机、手表平台组件。当前桌面内置节点依赖系统 `/usr/bin/python3`。最低部署目标为 macOS（苹果电脑系统）14、iOS（苹果手机系统）18、watchOS（苹果手表系统）11。

```sh
git clone https://github.com/Hanyan179/Tracebook.git
cd Tracebook
python3 scripts/prepare-node-runtime.py
python3 scripts/generate-project.py
xcodebuild -project VoiceMemory.xcodeproj -scheme VoiceMemoryMac \
  -destination 'platform=macOS' -derivedDataPath DerivedData/Mac \
  CODE_SIGNING_ALLOWED=NO build
```

手机、手表构建，独立节点、隔离测试和个人签名设置见[开发说明](docs/development.md)。压缩依赖从官方包仓库下载并校验，见[第三方依赖](THIRD_PARTY.md)。

## 资料与隐私

- 来源目录只读，先预览再确认。登录文件与完整配置不归档；常见凭证过滤不代表全部敏感信息识别。
- 导入资料不会自动发送给模型，也不会自动成为本人事实。资料性质由用户在导入时指定，默认未确认；不能根据第一人称或文件名推断作者。模型生成资料可阅读与检索，但不能作为本人记忆的原始依据。更正性质另存版本，保留旧文件与人工修改。
- 节点默认只监听本机。新资料类型不会静默扩大旧的外部读取授权。
- 带重点标记的录音使用新版清单；发送端和接收端都需更新。标记只表示原音中的时间，不表示转写、说话人或事实已经确认；实际手表到手机的系统传输仍需配对实体设备验收。
- 直连会核对接收资料库身份，同一地址换库或旧版收据首次升级时须在应用核对位置；确认后检查已有文件，缺失记录才补传。请同时更新电脑端，旧版本不具备资料库身份保护。
- 原音、数据库、个人配置、真实来源统计、本机交接和验收截图不在公开仓库中。
- 文字导出与可恢复备份是两个入口。备份未加密，需妥善保存；文档原件默认不复制，只有明确选择保留的副本才纳入备份；副本保留原内容与元数据，不执行全文脱敏。未留存的附件、外部来源目录及应用凭证需要独立保管。第 8 版备份支持带重点标记的录音清单，包含记忆文件合并、批量记忆核对、转写核对、模型核对记录及来源跳过位置，并可恢复此前第 1–7 版备份；新备份需使用更新后的应用恢复。

## 项目结构

```text
Apple/                    原生手机、手表、电脑界面
Sources/VoiceMemoryCore/   录音、导出、校验与持久队列
Tests/                    核心模块测试
node/                     本机资料节点与节点测试
integrations/             外部只读接入包
scripts/                  工程、依赖与公开文件检查
docs/                     公开架构、开发和研究资料
```

已有自动测试覆盖导入去重、压缩历史恢复、人工编辑保护、导出、引用约束和权限隔离。持续检查的状态以对应提交为准；合成测试不能代替真实模型、云盘或实体设备验收。
