# 智能体协作与界面规范

本文件供开源贡献者与编程助手使用。当前用户请求定义工作目标和授权，本文件不授予发布、账号访问或个人资料读取权限。维护者本机的 `AGENTS.md` 与交接可能包含本地环境说明，不进入公开仓库。

## 开始与完成

先读项目说明、架构、持续迭代清单和相关代码，核对分支与未提交修改。每次完成一项可验证的用户任务，再推进下一项。需要持续唤醒时使用已有调度能力；规则文件只记录长期约束，不保存每轮流水。

界面工作先运行现有应用，捕捉当前页面与操作结果，写出具体问题，再改代码。选择实际相关的审查、原生界面操作、构建与数据验证工具；工具数量不代表完成度。不要另起网页原型代替原生应用的修复。

## 用户路径

- 录音与文字：找到录音，回放原音，看清转写状态，校对文字，再提出有依据的记忆。
- 资料导入：选择来源，预览范围，确认归档，阅读原文，再提出记忆；源目录只读。
- 记忆审阅：看见待确认数量，核对原文片段及归属，再确认、修订、停用或恢复。建议不会因超时自动成为事实。
- 连接与同步：说明当前保存地点、已经收到什么、尚未完成什么，提供具体恢复入口。

## 界面约束

1. 沿用迹库品牌、现有颜色和系统图标，保持原生窗口与导航。手机底部固定为记录、对话、同步、我的，设置从“我的”进入。
2. 内容优先。列表页先显示搜索与资料，标语、重复品牌和教程不得挤走首屏内容。只在需要指导的空状态解释下一步。
3. 一个动作一个清晰入口。未配置时提供通向设置的操作；不能只留一个禁用按钮。完成状态与文件内容必须同步刷新。记忆在资料库保存成功和文字文件交付分别显示；部分文件失败须持久保存并恢复，不能重跑模型或重复确认来冒充补写。人工编辑冲突保留原件与另存结果，不能用自动重试覆盖。明确采用生成文件前先备份，并核对预览版本；文件处理与记忆事实修订分开。
4. 桌面侧栏按资料、整理与回顾、连接分组；列表使用可调宽度，正文保留阅读宽度并靠左，不将大段内容居中成展示海报。
5. 待确认记忆必须直接可见，显示准确数量。已确认、待确认与停用状态明确区分；不能只显示空的已确认列表而隐藏候选。没有搜索或筛选时，不把空的审阅队列解释为搜索失败；提供返回已确认内容的入口。
6. 手机分类、月份、标签等次要筛选放入明确的筛选入口，保留已启用条件数量和清除操作。主要触控动作以至少 44 点为目标。
7. 表单采用系统分组、明确标签和足够留边；次要说明放在对应操作旁。大字号下允许纵向重排和滚动，不能只靠缩小字体。
8. 中英文、深浅色、窄窗口和辅助字号逐项实际检查。界面翻译不改写资料原文；英文数量处理单复数。可使用契合品牌和资料场景的素材与轻量动效，优先用于选中切换、内容展开和操作反馈；动态效果遵守系统减少动态效果偏好。
9. 检索结果尽量直接打开保存位置附近的前后文；版本变化后保留旧片段并提示，不能重新搜索同一句话冒充历史位置。原文阅读保持句子中的来源名称与代码示例，不能用正则删除链接文字或把代码中的链接变成操作；文字字号跟随辅助设置，分页错误不得混入其他版本。
10. 每次修改都检查完整往返：进入、操作、结果、返回、重新打开。还要核对取消和失败路径，不以按钮有点击效果作为完成。

## 数据与模型

原文、模型提议和已确认记忆分别保存。模型输出必须能追溯到资料版本与原文片段，不能将助手回答、引用或他人发言直接归为用户事实。人工修改、历史版本和原音必须保留，重试不重复归档。 核对引用时按保存的版本与位置读取有限前后文；节点字符位置采用 Unicode（统一字符编码）标量，不能直接当成客户端可见字符数。内容版本或原位置不符时保留旧引用，不通过搜索相同文字假装恢复历史上下文。手动提出建议时，重复片段须让用户核对上下文并选择位置；字符限制、匹配与保存偏移遵循同一字符规则，不以看起来相同的重音或组合字符替代原文。匹配范围与截断应明确说明。

语音服务和文字模型使用独立配置；密钥由用户在应用中填写，不进入源码、日志、提示词或导出。没有密钥时可验证受控接口，但要保留真实识别和模型质量的验收缺口。新来源不自动获得外部读取授权或自动外发。批量整理先显示明确选择的范围、版本与服务，再发送；长资料分别显示所选正文、随请求发送的前后文和未处理范围，不能把处理覆盖等同于事实提取完整。分段引用由节点换算为完整原文位置，不让模型计算字符偏移。重启需明确继续，不把预览或配置密钥当成外发许可。暂停结束当前请求后停止后续资料，已保存结果复用，未知远端结果不能宣称不会重复计费。新旧记忆需要对照时，先展示双方依据，由用户明确选择重复、补充或替代；核对双方版本并原子保存处理结果、历史与检索状态。关系记录引用处理时的版本，不能随后来的人工编辑漂移。

## 验收与交付

按照开发说明执行与变更相符的检查。分别报告自动测试、构建、实际界面、模拟器、实体设备、真实模型和真实云同步。没有验证的项目就保留为未验证，不能用统计数字替代完整使用路径。

截图与合成数据留在忽略目录，公开说明只写可复现的行为与限制。提交前检查暂存树，排除凭证、个人路径、设备信息和真实资料。尊重用户的发布范围；当前机器有访问权限不代表获得部署或对外发送授权。
