# 官网与云端开发协作交接

更新于 2026-10-22。官网由后续云电脑助手负责；当前仓库提供客户端、节点、研究和能力状态。**本仓库目前没有已实现或已部署的官网。** 不把这个交接文件当作官网交付。

## 产品表达

工作品牌保持“迹库 / Tracebook（迹库）”。核心是用户自己的资料与记忆系统：通过自己选择的入口记录和导入，保留原文、时间与来源，逐步整理成可确认、可修订的记忆，文件由用户持有。

希望用户理解的三点：

1. 手机、手表负责方便地留下信息；电脑负责汇集、阅读和整理。
2. 语音、已有文档及本地工具输入都可以成为来源，每种来源按已实现范围说明。
3. 原文、模型建议、已确认记忆分层，资料可追溯和带走。

主要体验参考为 [Auday（全天录音与记忆应用）](https://auday.ai/)；参考其真实使用流程与价值表达。迹库保留自己的品牌、图标、原生导航和资料范围，不复制对方网站、截图、宣传数字或付费权益。

## 云电脑助手的工作范围

- 从 `https://github.com/Hanyan179/Tracebook` 获取当前代码，先读 `README.md`、`ROADMAP.md`、本文件与[体验原则](auday-experience.md)。本地维护者的私有交接不会上传，公共协作依赖这些文件。
- 建议官网单独放在 `website/`，通过独立分支和 Pull Request（合并请求）协作；网站构建及运行命令写入该目录的说明。不先假定某个框架或托管服务已经存在。
- 本地工作继续负责原生客户端与资料节点；官网任务避免修改 `Apple/`、`Sources/`、`node/`、设备签名及持久化数据契约。需要调整时在合并请求中说明依赖。
- 官网图片使用本项目已有品牌素材和经检查的合成数据截图；没有真实画面时保持文字说明，不伪造已实现功能。个人录音、聊天、接口密钥、设备编号和本机路径不得进入网站或构建日志。
- 云电脑当前是开发协作环境，不自动成为用户资料库、转写服务或手机同步服务器。运行时接入需要另行实现和验收。
- 官网部署、域名、账号或收费服务需要明确的目标与授权；当前代码推送不等同于这些操作已获授权。

## 官网验收

1. 电脑宽屏、手机窄屏、中英文、键盘和减少动态效果偏好下内容可读、操作可达。
2. 源码、构建、迭代与隐私链接有效；下载按钮只指向实际存在的对应版本。
3. 每项产品能力能对应到代码或验收依据，开发中能力明确标记。
4. 不收集或自动上传个人资料，不增加未经确认的分析、表单或账号服务。
5. 提交实际预览和检查结果，再按明确目标部署；不可将静态页面通过称为客户端或云同步通过。
